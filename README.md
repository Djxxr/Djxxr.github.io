# djxxr.github.io

Strona z linkami do moich profili.

## Edycja treści

Wszystko (bio, avatar, linki, Discord) jest w jednym pliku: [`src/config.ts`](src/config.ts).
Avatar wrzuć do folderu `public/` (np. `public/avatar.jpg`) i wpisz `"/avatar.jpg"`.

## Komendy

```bash
npm install      # pierwsza instalacja
npm run dev      # podgląd na żywo: http://localhost:5173
npm run build    # wersja produkcyjna do folderu dist/
```

Każdy push na gałąź `main` automatycznie publikuje stronę na GitHub Pages.

## Technologie

React 19 · TypeScript · Vite · Tailwind CSS 4 · Motion · GSAP · Three.js (React Three Fiber) · Lenis
